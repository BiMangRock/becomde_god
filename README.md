# 신되기

섬 하나를 다스리는 신이 되는 2D 갓 게임입니다. 이미지 파일 없이 HTML 캔버스와 도형만으로 그립니다.

인간들은 스스로 살아갑니다. 먹을 것을 모으고, 짝을 짓고, 아이를 낳고, 모여서 부족을 세우고, 마을을 짓고, 거래하고, 전쟁을 합니다. 신은 비·축복·번개·운석 같은 권능으로 세상에 손을 댑니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 서버나 빌드가 필요 없습니다.

GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로 공유할 수도 있습니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 확대 / 축소 | 마우스 휠, 두 손가락, 화면 왼쪽 아래 +/− |
| 지도 이동 | 살펴보기 도구로 드래그, 오른쪽 버튼 드래그, WASD·방향키 |
| 사람·마을 보기 | 살펴보기 도구로 클릭 |
| 권능 쓰기 | 왼쪽에서 권능을 고르고 지도 클릭 (땅 올리기/내리기는 누르고 있기) |
| 속도 | 스페이스(일시정지), 1·2·3 |

확대할수록 더 자세히 보입니다.
- 멀리서: 부족 색 점
- 중간: 사람 모양, 나무, 산
- 가까이: 얼굴, 머리 모양, 옷, 들고 있는 짐, 족장의 관, 전사의 창, 이름, 감정 표시

## 들어 있는 것

- **세계**: 무작위 섬 (바다, 모래, 초원, 숲, 언덕, 산, 설산). 식량과 나무는 다시 자라고, 가뭄이 오기도 합니다.
- **인간**: 이름, 나이, 성별, 성격 2개(용감한, 탐욕스러운, 신앙심 깊은 등), 배고픔, 건강, 신앙, 행복, 금화, 가족 관계. A* 길찾기로 움직입니다.
- **부족**: 떠돌이 3명 이상이 한동안 함께 지내면 부족이 생깁니다. 족장 선출, 집과 신전 짓기, 직업 배분, 인구가 많아지면 분열, 기근이 들면 이주합니다.
- **경제**: 부족마다 창고와 금고가 있고, 시장 가격은 수요와 공급으로 정해집니다. 일꾼은 자원을 맡기고 금화를 받고, 그 금화로 식량을 삽니다. 광석은 금화로 만들어집니다. 상인은 싼 곳에서 사서 비싼 부족에 팝니다.
- **외교와 전쟁**: 가까운 부족끼리는 사이가 나빠지기 쉽고, 거래하면 좋아집니다. 사이가 아주 나빠지면 전쟁이 나고, 전사가 적 마을을 약탈합니다. 진 쪽은 금화를 바칩니다.
- **신앙**: 인간들의 믿음이 신앙 포인트가 됩니다. 사제와 신전은 신앙을 더 모읍니다. 기적을 보면 믿음이 커지고, 재앙을 보면 두려움 속에 믿게 됩니다.
- **관계**: 사람마다 아는 사람 최대 16명에 대해 아래 수치를 기억합니다.

  | 수치 | 범위 | 오르는 일 / 내리는 일 |
  | --- | --- | --- |
  | 호감 | -100~100 | 수다, 선물, 위로 / 다툼 |
  | 사랑 | 0~100 | 첫눈에 반함, 데이트 / 다툼, 멀어짐, 바람 |
  | 신뢰 | -100~100 | 도움, 빚 갚기 / 도둑질, 배신, 거짓 |
  | 존경 | 0~100 | 상대가 족장·사제·치료사이거나 나이와 재산이 많을수록 / 악명 |
  | 두려움 | 0~100 | 상대의 악명, 싸움 실력, 전사·경비병 |
  | 원한 | 0~100 | 주먹다짐, 도둑맞음, 배신, 빚을 안 갚음 / 세월, 좋은 만남 |
  | 질투 | 0~100 | 연적, 부자에 대한 부러움 |
  | 빚 | 금화 | 친구끼리 돈을 빌려주고 갚습니다. 오래 안 갚으면 원한이 생깁니다 |

  이 수치들로 관계 이름이 정해집니다: 배우자, 연인, 비밀 연인, 썸, 짝사랑, 부모, 자녀, 형제자매, 원수, 연적, 스승, 제자, 은인, 절친, 존경하는 사람, 두려운 사람, 라이벌, 친구, 빚진 사람, 앙숙, 옛 연인, 전 배우자 등. 성격 궁합(같은 성격은 +, 반대 성격은 -)도 영향을 줍니다.
- **성격 (한 사람당 3개)**: 용감한/겁많은, 탐욕스러운/너그러운, 부지런한/게으른, 신앙심 깊은/의심 많은, 정직한/교활한, 다정한/냉정한, 충동적인/침착한, 질투심 많은, 호기심 많은, 야심찬. 일, 다툼, 위로, 사랑, 범죄, 마음의 병에 모두 영향을 줍니다.
- **마음**: 스트레스와 외로움이 쌓이면 기분이 나빠집니다. 오래 슬프면 우울증, 스트레스가 쌓이면 불안증, 끔찍한 일(살인 목격, 자식을 잃음, 전쟁)을 겪으면 트라우마, 거듭 배신당하면 편집증이 생길 수 있습니다. 마음의 병은 일과 어울림을 바꿀 뿐 사람을 위험하게 만들지는 않습니다. 친구의 위로, 배우자, 치료사의 상담, 신의 치유로 회복합니다.
- **범죄와 벌**:
  - 범죄: 가난하거나 탐욕스러우면 도둑질을 하고, 깊은 원한은 폭행이나 살인으로 이어집니다. 원한이 아주 깊으면 상대의 뒤를 몰래 밟기도 합니다.
  - 목격과 수사: 범행을 본 사람이 있으면 바로 수배되고, 아무도 못 봤으면 미제 사건으로 남습니다. 미제 사건은 경비병이 많을수록 빨리 풀립니다. 가까운 사람은 범인을 감싸 주기도 합니다.
  - 체포와 재판: 경비병이 수배자를 쫓아 붙잡고, 족장이 재판해서 감옥살이, 벌금, 추방 중 하나를 선고합니다. 족장이 죄를 지으면 먼저 자리에서 쫓겨납니다.
  - 감옥과 탈옥: 사람이 많거나 범죄가 잦은 부족은 감옥을 짓습니다. 죄수는 가끔 탈옥하고, 바깥의 연인이나 친구가 도와주기도 합니다. 감옥이 운석이나 번개로 부서지면 죄수가 모두 달아납니다.
  - 무법자와 도적단: 추방자와 탈옥수는 무법자가 되어 마을을 피해 다닙니다. 무법자 셋 이상이 모이면 도적단을 만들어 마을을 습격합니다. 오랜 세월이 지나면 다른 부족에서 새 삶을 시작하기도 합니다.
- **직업**: 채집꾼, 농부(밭을 일굼), 사냥꾼, 어부, 나무꾼, 광부, 대장장이(도구로 일 효율 최대 +30%), 상인, 사제, 치료사, 경비병, 전사, 족장. 성격에 맞는 일을 고르고, 같은 일을 하는 연장자를 스승으로 모시기도 합니다.
- **동물**: 사슴(도망), 멧돼지(반격), 늑대(마을 밖에 혼자 있는 사람을 노림). 해마다 번식하고, 사냥꾼이 잡습니다.
- **주민의 행동**: 수다, 아이들 놀이, 가족과 함께하기, 선물, 슬픈 친구 위로, 말다툼과 주먹다짐, 친구 찾아가기, 바닷가·숲·언덕 데이트, 모닥불 축제의 춤.
- **연애와 가정**: 첫눈에 반하기, 우정이 사랑으로 바뀌기, 고백(성공하거나 거절당하기), 연인, 결혼식(하객도 기뻐함), 임신 9개월, 출산(드물게 난산), 이별, 이혼, 바람(배우자에게 들키면 질투와 배신). 오래 혼자인 사람은 부족의 소개로 짝을 만나기도 합니다.
- **기분**: 배고픔과 건강, 그리고 기분 요인이 더해져 행복 점수가 됩니다. 기분 요인에는 사랑에 빠짐 +20, 결혼 +30, 이별 -25, 배우자를 잃음 -40, 축제 +16, 번개 공포 -15 등이 있습니다. 기분은 황홀함, 행복함, 즐거움, 평온함, 우울함, 비참함, 절망, 화남, 질투와 분노로 나타납니다. 기분이 좋으면 일이 빨라지고 사랑에 잘 빠지며, 나쁘면 다툼이 잦아집니다.
- **개별 이야기**: 모든 인간이 자기 인생 기록을 가집니다 (태어남, 결혼, 자녀, 직업, 거래, 전투, 기적 목격, 가족의 죽음).
- **기록관**: 죽은 사람의 요약된 이야기를 보관합니다.

## 사랑을 다루는 권능

| 권능 | 효과 |
| --- | --- |
| 사랑의 화살 ♥ (15) | 두 사람을 차례로 누르면 서로 운명적인 사랑에 빠집니다. 둘 다 혼자면 연인이 되고, 한쪽에 짝이 있으면 금지된 사랑(바람)이 시작됩니다. 이미 짝인 둘이면 식은 사랑이 다시 불타오릅니다. |
| 다산 ✿ (20) | 주변 부부에게 아이가 생기기 쉬워지고 출산이 안전해집니다. |
| 불화 ☁ (15) | 주변 사람들이 서로 미워하고 다툽니다. 연인 사이도 흔들립니다. |
| 치유 ✚ (20) | 주변 사람의 상처, 마음의 병, 스트레스, 원한을 씻어 줍니다. |

## 개별 이야기와 메모리

인간마다 이야기를 남겨도 메모리 걱정은 거의 없습니다. 이렇게 관리합니다.

1. **관계와 기분도 개수 제한**: 관계는 한 사람당 16명까지 기억합니다(한 명당 수치 9개 정도). 넘치면 가족·연인을 빼고 가장 약한 관계부터 잊습니다. 기분 요인은 8개까지입니다.
2. **이야기 개수 제한**: 살아 있는 사람은 최근 40개까지만 기억합니다. 태어난 기록은 항상 남깁니다. 한 줄은 `{연도, 문장}` 하나뿐입니다.
3. **자잘한 일은 기록하지 않음**: 나무 한 번 베기 같은 반복 행동은 남기지 않고, 인생에 의미 있는 일만 남깁니다.
4. **죽으면 요약**: 죽은 사람의 큰 객체는 버리고, 최근 이야기 15개와 기본 정보만 기록관에 남깁니다. 최대 300명이며, 족장·영웅·장수한 사람은 더 오래 보존됩니다.
5. **가족은 id로 연결**: 부모와 자녀는 객체가 아니라 `{id, name}`으로 저장합니다. 그래서 죽은 조상 객체가 족보를 따라 줄줄이 메모리에 남지 않습니다.

계산해 보면 인구 1,200명(최대치) × 이야기 40줄 × 한 줄 약 100바이트는 약 5MB입니다. 브라우저에서는 문제없는 크기입니다.

## 파일 구조

```
index.html        화면 뼈대
css/style.css     스타일
js/util.js        설정, 이름·성격 생성, 한국어 조사
js/world.js       지형 생성, 자원, A* 길찾기
js/human.js       인간의 행동 (먹기, 일, 장사, 싸움, 기도)
js/tribe.js       부족 (창고, 가격, 직업, 외교, 이주)
js/social.js      관계, 기분, 연애, 결혼, 임신, 축제, 사랑의 권능
js/mind.js        신뢰·존경·두려움·원한·질투·빚, 스승, 스트레스, 마음의 병, 치료
js/crime.js       절도·폭행·살인, 목격과 수사, 체포, 재판, 감옥, 탈옥, 도적단
js/wildlife.js    사슴·멧돼지·늑대, 사냥
js/sim.js         세계 시간, 출생·죽음, 부족 생성·분열, 전쟁, 신의 권능
js/render.js      캔버스 그리기 (확대 단계별 디테일)
js/ui.js          정보 패널, 기록관, 세계 기록
js/main.js        입력 처리와 게임 루프
```

`js/sim.js`까지는 DOM을 쓰지 않아서, Node에서도 시뮬레이션만 따로 돌려 볼 수 있습니다.
